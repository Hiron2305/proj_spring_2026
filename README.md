Работа с проектом
1. Главное меню. Здесь пользователь настраивает параметры для фильтрации данных о животных:

1.1 Формат данных JSON/XML: преобразует базу данных в удобный нам формат.

1.2 Только приюты с открытой территорией: исключает из выборки закрытые приюты.

1.3 Только животные с клаустрофобией: оставляет в выборке только животных с клаустрофобией.

1.4 Выберите приют: позволяет искать питомцев либо по всем приютам сразу, либо по конкретному одному приюту.

1.5 Выберите вид животного: позволяет выбрать тип животного для поиска.

1.6 Показать питомцев: применяет все заданные параметры для фильтрации и показывает результаты в виде таблицы.

2. Таблица питомцев. Выводит всех животных, которые подошли по условиям фильтрации:

2.1 Добавить питомца: открывает дополнительное окно, в котором можно самостоятельно ввести все параметры нового животного (кличку, возраст, вес, пол, тип и уникальные характеристики) и добавить его в выбранный приют.

2.2 Удалить питомца: необходимо выделить питомца в таблице, после чего нажать на кнопку "Удалить выбранного" для его удаления из базы.

2.3 Сохранить подборку в файл: генерирует отчет по текущей отображающейся таблице в отдельный файл в директорию проекта.
